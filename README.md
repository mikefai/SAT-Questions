# SAT 2026 Master Hub: Blueprint, Question Types & Error Diagnostic Tracker

An interactive web application designed for the **2026 Digital SAT Suite of Assessments**.

## 🌟 Key Features

1. **📊 2026 SAT Blueprint & Question Counts**
   - **Reading and Writing**: 54 questions (2 modules × 27 Qs) across 4 domains (Craft and Structure, Information and Ideas, Standard English Conventions, Expression of Ideas).
   - **Math**: 44 questions (2 modules × 22 Qs) across 4 domains (Algebra, Advanced Math, Problem-Solving & Data Analysis, Geometry & Trigonometry) with full Desmos integration.
   - Interactive visual charts comparing question volumes and timing allocations.

2. **📖 Question Type Encyclopedia ("What They're Asking")**
   - Comprehensive directory of all Reading & Writing and Math question types.
   - Prompt stems, core tested skills, trap/distractor alerts, and master solving strategies.
   - Live interactive sample questions with immediate solution feedback and explanations.

3. **🎯 Learner Entry & Error Diagnostic Tracker**
   - Log practice errors by test source, subject, question type, error reason, confidence, and takeaways.
   - Auto-ranked leaderboard of the **Most Wrongly Answered Question Types**.
   - Visual charts for mistake distribution by domain and root causes.
   - Targeted AI-style diagnostic prescription and recommendations.
   - Export practice logs to JSON or CSV.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Optional: Serve with Python
python -m http.server 8000
```
